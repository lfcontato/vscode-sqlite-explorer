# Publisher logo

Publisher: `lfcontato` (Luis Fernando Pereira).

- `publisher-logo-source.png`: original 1254 × 1254 PNG from the built-in image generation tool.
- `publisher-logo-128.png`: 128 × 128 PNG resized for the Visual Studio Marketplace publisher profile.
- Destination: https://marketplace.visualstudio.com/manage/publishers/lfcontato (Details → Logo).

The logo was generated with the built-in image tool, then resized without changing its design. It is the publisher identity, separate from the SQLite Explorer extension icon.

## Final prompt

Use case: logo-brand. Asset type: square publisher profile logo for Visual Studio Marketplace, legible when displayed at 128 x 128 pixels. Create one polished flat minimalist typographic monogram. Exact text: "LF" in uppercase white, bold geometric sans-serif letterforms, optically centered with generous breathing room, together occupying approximately 64 percent of square width. Background: completely uniform solid deep navy blue (#10243A), full bleed to all four edges. The letters L and F remain immediately readable; crisp clean straight edges, refined proportions, contemporary professional developer brand. One final square logo, straight-on artwork only. No border, no rounded container, no gradients, no shadows, no texture, no perspective, no mockup, no captions, no other text, no symbols, no watermark.

# Support

Report reproducible problems at [GitHub Issues](https://github.com/lfcontato/vscode-sqlite-explorer/issues).

Include the extension version, VS Code version, operating system, whether WSL/SSH is involved, and the steps to reproduce. Prefer a small synthetic database; do not upload private databases, credentials, personal data, or access tokens.

For save conflicts, retain the pending draft until you have compared the external changes. Use **Discard changes** and reload only when you intend to abandon that draft. Before each write batch, a consistent backup is created next to the source database; its path appears after a successful save.
